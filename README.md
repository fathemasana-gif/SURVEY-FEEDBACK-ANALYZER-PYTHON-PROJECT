# SURVEY-FEEDBACK-ANALYZER-PYTHON-PROJECT

## About the Project

This is a Python project that collects and analyzes survey feedback. It cleans the feedback text and helps find common words and customer ratings.

## Features

* Added new feedback from users
* Clean feedback by removing punctuation and extra spaces
* Count words like good, poor, and excellent
* Calculate the average rating
* Find the longest feedback and unique words

## Tools Used

* Python
